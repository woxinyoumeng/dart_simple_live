### 关键发现
1. Wails v3 alpha2 API: `RegisterService(NewService(T))` 而非 `RegisterBindings`
2. 前端调用: `window.wails.Call.ByName('main.App.MethodName')`
3. Wails runtime 需要在 index.html 中以 `<script type="module" src="/wails/runtime.js">` 引入（在 app 代码之前）
4. Vite 构建后需重新注入 runtime.js script 标签
5. Naive UI 使用 `app.use(naive)` 全局注册会在 WKWebView 中报错，改用组件级 `import { X } from 'naive-ui'` + `<script setup>` 方式
6. B站推荐 API: `room/v1/Room/get_user_recommend`（免 WBI 签名）
7. B站播放 API: `room/v1/Room/playUrl`（免签名）
